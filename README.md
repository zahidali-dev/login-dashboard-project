# 🔐 Mini Login & Dashboard Project

A simple and responsive **Login + Dashboard** web project built with **HTML, CSS, and JavaScript**.  
This project demonstrates form validation, navigation, and responsive UI — perfect for beginners learning front-end basics.

---

## 🎯 Features
- ✅ Login and Sign-Up Forms  
- ✅ Dashboard Page with clean UI  
- ✅ Responsive design using Flexbox  
- ✅ JavaScript-based form validation  
- ✅ Pure front-end (no frameworks, no backend)

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3 (Flexbox & Grid)**
- **Vanilla JavaScript (ES6)**
